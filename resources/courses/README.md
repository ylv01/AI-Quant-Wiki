# 课程索引

只列大学或项目官方课程页面。课程内容可能随学期更新，表中不固定某一年度版本。

| 课程 | 机构 | 方向 | 适合阶段 | 官方地址 |
|---|---|---|---|---|
| CS336: Language Modeling from Scratch | Stanford University | 语言模型、数据、训练与系统 | AI 预训练与训练系统 | [课程官网](https://cs336.stanford.edu/) |
| CS224N: Natural Language Processing with Deep Learning | Stanford University | NLP、Transformer 与 LLM | AI 基础至后训练 | [课程官网](https://web.stanford.edu/class/cs224n/) |
| CS231n: Deep Learning for Computer Vision | Stanford University | 神经网络与计算机视觉 | AI 基础与多模态 | [课程官网](https://cs231n.stanford.edu/) |
| Hugging Face LLM Course | Hugging Face | Transformer、Tokenizer、微调与应用 | AI 基础至微调 | [课程官网](https://huggingface.co/learn/llm-course/chapter1/1) |
| PyTorch Tutorials | PyTorch | 张量、Autograd、训练与分布式 | AI 基础与训练系统 | [官方教程](https://docs.pytorch.org/tutorials/) |
| Finance Theory I | MIT OpenCourseWare | 现值、固定收益、组合、CAPM 与衍生品 | 金融工程基础 | [课程官网](https://ocw.mit.edu/courses/15-401-finance-theory-i-fall-2008/) |
| Corporate Finance | NYU Stern / Aswath Damodaran | 公司金融、风险与估值 | 金融市场与资产定价基础 | [课程官网](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/corpfin.html) |

## 使用建议

- AI 路线可先使用 PyTorch Tutorials 与 CS231n，再进入 CS224N 和 CS336。
- 金融路线可用 MIT Finance Theory I 建立主干，用 NYU 课程补充公司金融和估值视角。
- 实际学习时以课程官网当前先修要求、讲义与作业说明为准。
