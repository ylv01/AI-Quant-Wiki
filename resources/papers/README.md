## 维护规则

- 核对题名、年份和官方来源后再添加。
- 每个主题首轮不超过 5 篇，按基础到进阶排序。
- 不增加阅读、复现或完成度字段。
- 同一论文只在最相关的集中索引出现，主题文档可按需要引用。
