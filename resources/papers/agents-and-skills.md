# Agent 与 Skills 核心论文

| 年份 | 论文 | 主题 | 推荐理由 | 难度 | 官方来源 |
|---:|---|---|---|---|---|
| 2022 | ReAct: Synergizing Reasoning and Acting in Language Models | 推理与行动 | 将推理、工具行动和环境观察交错，为工具型 Agent 提供基础循环。 | 中级 | [arXiv](https://arxiv.org/abs/2210.03629) |
| 2023 | Toolformer: Language Models Can Teach Themselves to Use Tools | 工具学习 | 探索通过自监督数据让模型学习何时以及如何调用外部工具。 | 进阶 | [arXiv](https://arxiv.org/abs/2302.04761) |
| 2023 | Reflexion: Language Agents with Verbal Reinforcement Learning | 反思与记忆 | 研究用语言反馈和轨迹记忆改进后续尝试的方式。 | 进阶 | [arXiv](https://arxiv.org/abs/2303.11366) |
| 2023 | AgentBench: Evaluating LLMs as Agents | Agent 评价 | 在多类交互环境中评价 Agent，适合理解任务成功与轨迹指标。 | 进阶 | [arXiv](https://arxiv.org/abs/2308.03688) |
